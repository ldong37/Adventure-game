Building The Lost Temple taught me to use a single variable (currentState) as the application's "brain" to track player decisions through a story timeline. Instead of hardcoding separate web pages, I used JavaScript DOM manipulation to dynamically clear previous choices and generate new paths on the fly. Implementing browser debugging tools to pause execution at breakpoints gave me firsthand insight into variable tracking before the user interface re-renders. Finally, managing my file updates within Visual Studio Code helped me master core Git workflows, including branch creation and building a clean commit history on GitHub.
